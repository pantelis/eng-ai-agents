# MIT Vision Book Reference Assets

This directory stores the local offline MIT *Foundations of Computer Vision* Chapter 40 figures used by the Chapter 40 stereo notebook.

Git history for this chapter did not contain local MIT reference image files, so these four assets were restored from the official MIT chapter page to remove remote notebook-image dependencies. The Chapter 40 notebook now uses the more directly relevant rectified-stereo references 40.5 and 40.7 instead of the earlier 40.12 and 40.13 choices.
