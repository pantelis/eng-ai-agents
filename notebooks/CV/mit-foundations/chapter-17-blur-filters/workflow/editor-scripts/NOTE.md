# No figure editors for this chapter — intentionally

Ch 47's figures are geometric diagrams (cameras, pyramids, vanishing points)
whose element positions had to be dragged to match the book, so each got a
`build_fig47_*.py` HTML editor here.

Chapter 17's figures are **computed** — filtered images, kernel stems, DFT
magnitude curves, kernel-vs-Gaussian overlays. Every element's position is fixed
by the math, so there is nothing to place by hand and no editor is needed. See
`../README.md` ("figures are computed, not hand-placed") for the full rationale.
