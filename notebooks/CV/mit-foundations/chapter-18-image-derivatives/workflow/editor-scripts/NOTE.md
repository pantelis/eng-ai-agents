# No figure editors for this chapter — intentionally

As in Ch 17, every figure here is **computed** — derivative maps, kernel stems,
DFT curves, Gaussian/Hermite profiles, the Mexican-hat surface, the Retinex
decomposition. Each element's position is fixed by the math, so there is nothing
to place by hand and no drag-and-drop editor was needed (unlike Ch 47's
geometric camera diagrams). See `../README.md` for the rationale.
